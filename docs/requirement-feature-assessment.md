# 功能点评估展示与 LawAgent 核查

功能点列表展示评估报告中的实现判断、事实、验证和剩余范围。需求级 Task 用于查看工作记录和导航，默认折叠；功能点没有 Task 绑定也能展示评估，不由 Task 数量、关闭状态或执行记录计算功能完成率。

## 报告读取与当前选择

- 兼容 `功能点`、`原功能点`、`功能点编号`、`功能义务`，保留 F 编号和原文件行号；也读取明确的“原功能N”或与功能正文完全一致的名称，不按表格行序猜测对应关系。其他需求的限定编号不会附到本需求。
- 兼容实施判断、核对结果、实现与验证、完整范围剩余与限制等列名。未知列仍按原标签显示，不隐藏到第二层原文中。
- 只有独立的实现判断列支持明确的实现分类。混合事实或验证 PASS 不推导功能完成；有边界但没有明确逐点状态的记录显示“已评估”。明确的“无法评估”“未通过”分别显示结果与原因。
- 所选目标、范围、对象使用既有 `selectAssessment` 核对；不会按修改时间替代验收结论。当前报告与其他对象、范围、历史报告的逐点行分开。
- 仅浏览时默认打开评估时间较新的报告供阅读，并保留报告选择；其结论以“已评估”显示且限定于报告对象与范围。当前适用性单独检查和说明，不把无法适用当成未做评估。
- 所选范围报告没有逐点表格时显示“未逐点列出”，不从整项或子范围满足结论推导所有点满足。重复同编号行标为记录冲突。
- 每个功能点默认折叠，点击标题后在当前需求页一次展开完整定义、范围边界、验收要求和当前评估说明，不截断、不要求再次展开描述或跳页查找。明确移至独立需求的功能点，按原功能编号就地读取对应行为；不得只显示“已移至”或以原文入口代替完整描述。原文与历史材料保持次要入口。
- 原始评估字段、报告时间、对象版本和来源折叠保存。专项补充说明和完整报告仍有原文入口。
