## 总览性能优化（前三项）

- 折叠的验收分组、未排序需求、Task 索引、文档核对和任务记录仅在展开时挂载，收起后卸载。扫描提示、文件列表、文档登记、登记依据、候选文件、产品诊断和验收报告采用每页 40 条的分页。
- 新增 `/api/projects/:id/overview`，沿用完整快照的业务选择器生成摘要。总览首屏和验收摘要弹窗只读取该摘要；需要文档记录时才请求完整快照，并携带 `snapshotId` 防止混用不同版本。详细记录的同版本请求在当前总览页面内复用。
- 摘要按内容计算 revision；已知版本请求省略未变化的正文。刷新提交只返回小型状态，轮询复用原有数据对象；项目列表未变化时不触发状态替换，稳定导航回调和总览 memo 避免重复渲染。

这些改动保留手动刷新、服务重启后恢复缓存与已有后台核对规则；没有新增自动文件监听或定时刷新配置。首次展开完整详细记录仍需传输完整快照，需求视图等页面也仍使用完整数据。

## 报告结论视觉区分与筛选

卡片顶部按报告结论显示色条，验收标签和弹窗统一使用颜色与符号：已满足为绿色 ✓，部分满足为琥珀色 ◐，尚未判定为蓝灰色 ?，未满足为红色 ×。原报告结论保留其颜色；验收适用性待核对另用黄色 ! 标记。多结论卡片以多段色条展示，保留范围差异，不合并成整个需求的最终结论。

路线图筛选支持结论多选（任一命中）、叠加验收待核对，以及 Task 有／无登记关联、关联待核对、含进行中／已完成／已关闭 Task、状态待核对。无验收记录单独筛选，不视为尚未判定。身份未确认的登记关联可命中“关联待核对”，不会误归入“无 Task 关联”；已关闭不会命中已完成。所有类别数量按需求计数，存在多份不同结论时类别数量可重叠。

筛选适用于已规划和未指定顺序的需求，保留原需求序号，并在筛选时展开未指定顺序的匹配项。查看详情后返回当前项目可保留筛选条件；切换项目按项目分别保存当前浏览会话的条件。筛选使用现有轻量摘要，不读取完整快照。

本轮 20 项相关单元测试、类型检查、生产构建、格式检查与生产总览浏览器回归通过。浏览器回归验证结论颜色／符号、结论多选、与待核对及 Task 组合、无匹配提示、清除筛选、原序号保留、未排序匹配项展示及 1440／1024／390 宽度等高无溢出；结果在 `output/playwright/overview-BzlkOe/result.json`。

真实 TermLink 66 个已规划需求中，“部分满足＋待核对”匹配 14 项，再加“无 Task 关联”匹配 9 项；此次交互无完整快照请求、无浏览器错误。1920／1440／1024／390 宽度检查通过，观察结果与截图位于 `output/playwright/overview-status-20261013/`。
